# GetGoals Mobile App

Flutter mobile application for GetGoals AI English Coach.

## Setup

```bash
flutter pub get
flutter run
```

## Structure

```
mobile-app/
├── lib/
│   ├── main.dart
│   ├── core/          # Constants, theme, utils
│   ├── models/        # Data models
│   ├── services/      # API services
│   ├── screens/       # Screen widgets
│   ├── widgets/       # Reusable widgets
│   └── providers/     # State management
├── android/
├── ios/
└── pubspec.yaml
```
