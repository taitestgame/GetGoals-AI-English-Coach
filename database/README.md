# GetGoals Database

SQL Server database for GetGoals AI English Coach.

## Files

| File | Description |
|------|-------------|
| `schema.sql` | Database schema - tables, foreign keys, indexes |
| `seed_data.sql` | Sample data for development |
| `procedures.sql` | Stored procedures |
| `views.sql` | Database views |

## Setup

1. Open SQL Server Management Studio
2. Run `schema.sql` to create the database and tables
3. Run `seed_data.sql` to insert sample data
4. Run `procedures.sql` to create stored procedures
5. Run `views.sql` to create views
