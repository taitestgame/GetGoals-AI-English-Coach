Phân chia công việc 
1. Bằng: Database và AI
Thành viên 1 chịu trách nhiệm phát triển phần giao diện web của hệ thống, đồng thời đảm nhận phần AI của đề tài. Đây là vị trí kết hợp giữa xây dựng giao diện cho người dùng trên nền tảng web và phát triển chức năng thông minh làm nổi bật tính ứng dụng của hệ thống.
Công việc cụ thể
Phát triển giao diện web bằng React
Xây dựng các màn hình và chức năng trên web như:
đăng nhập / đăng ký
trang chủ
hồ sơ người dùng
dashboard
quản trị cơ bản (admin)
hiển thị kết quả học tập / kết quả xử lý AI
Thiết kế và xây dựng dashboard/admin
Hiển thị các kết quả phân tích, dự đoán hoặc gợi ý do AI trả về
Xử lý phần mô hình AI
Xây dựng logic gợi ý hoặc thuật toán đề xuất
Tiền xử lý dữ liệu đầu vào phục vụ AI
Phối hợp với thành viên phụ trách backend để kết nối AI vào hệ thống
Kiểm thử phần hiển thị dữ liệu AI trên web
Vai trò chính
Chịu trách nhiệm phần giao diện và trải nghiệm của hệ thống trên nền tảng web
Đảm nhận phần cốt lõi về AI và logic thông minh của đề tài

2. Tài: Phụ trách Backend Lead và Phụ trách Web
Thành viên 2 giữ vai trò Backend Lead, chịu trách nhiệm chính về phần xử lý phía máy chủ, dữ liệu và kiến trúc tổng thể của hệ thống. Đây là vị trí trung tâm, đảm bảo toàn bộ web, mobile và AI có thể kết nối và vận hành ổn định.
Công việc cụ thể
Xây dựng backend bằng FastAPI
Thiết kế và quản lý cơ sở dữ liệu SQL Server
Thiết kế kiến trúc tổng thể của hệ thống
Xây dựng các API phục vụ web và mobile
Xử lý các chức năng chính như:
đăng ký / đăng nhập
xác thực người dùng
phân quyền
quản lý hồ sơ người dùng
quản lý dữ liệu bài học / bài kiểm tra / kết quả
lưu trữ lịch sử hoạt động
Xử lý business logic của hệ thống
Kết nối backend với database
Tích hợp AI vào backend để cung cấp kết quả cho web và mobile thông qua API
Hỗ trợ các thành viên khác trong quá trình gọi API và kiểm thử dữ liệu
Đảm bảo hệ thống backend hoạt động ổn định, bảo mật và đúng luồng xử lý
Vai trò chính
Chịu trách nhiệm phần lõi kỹ thuật của dự án
Đảm bảo luồng dữ liệu, API, xác thực và kết nối hệ thống hoạt động chính xác
Là người định hướng và chịu trách nhiệm về mặt kiến trúc backend

3. Mỹ: Phụ trách Mobile Flutter Lead và UI/UX Frontend
Thành viên 3 chịu trách nhiệm phát triển phần ứng dụng mobile bằng Flutter, đồng thời giữ vai trò Frontend Lead để hỗ trợ thống nhất phong cách giao diện giữa web và mobile. Đây là vị trí tập trung vào trải nghiệm người dùng trên thiết bị di động và đảm bảo tính nhất quán trong thiết kế giao diện toàn hệ thống.
Công việc cụ thể
Phát triển ứng dụng mobile bằng Flutter
Xây dựng các màn hình chính trên mobile như:
splash screen
onboarding
đăng nhập / đăng ký
trang chủ
danh sách nội dung / chức năng chính
trang kết quả
trang hiển thị gợi ý từ AI
Kết nối ứng dụng mobile với API backend
Tối ưu giao diện và trải nghiệm trên thiết bị di động
Đảm bảo ứng dụng có thể chạy ổn định trên cả Android và iOS
Kiểm thử tương thích giao diện, điều hướng và hiệu năng trên mobile
Hỗ trợ thống nhất thiết kế frontend toàn hệ thống
Phối hợp với thành viên 1 để đảm bảo giao diện web và mobile có phong cách đồng bộ
Đề xuất cải thiện UI/UX để tăng tính thân thiện với người dùng
Vai trò chính
Chịu trách nhiệm chính về nền tảng mobile
Đảm bảo chất lượng giao diện và trải nghiệm người dùng trên ứng dụng di động
Hỗ trợ thống nhất phong cách thiết kế giữa các nền tảng frontend
