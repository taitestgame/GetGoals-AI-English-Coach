# GetGoals Web Frontend

React web application for GetGoals AI English Coach.

## Setup

```bash
npm install
npm run dev
```

## Structure

```
web-frontend/
├── public/          # Static files
├── src/
│   ├── components/  # Reusable components
│   ├── pages/       # Page components
│   ├── services/    # API service calls
│   ├── context/     # React context providers
│   ├── hooks/       # Custom hooks
│   ├── layouts/     # Layout components
│   ├── routes/      # Route configuration
│   └── styles/      # CSS styles
└── package.json
```
