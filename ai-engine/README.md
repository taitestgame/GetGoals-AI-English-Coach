# GetGoals AI Engine

AI/ML module for English level prediction and learning roadmap recommendation.

## Structure

```
ai-engine/
├── data/           # Training data
├── notebooks/      # Jupyter notebooks for analysis
├── models/         # Trained model files
├── src/            # Source code
└── tests/          # Unit tests
```

## Setup

```bash
pip install numpy pandas scikit-learn jupyter
```

## Usage

### Train Models
```bash
python src/train_model.py
```

### Run Tests
```bash
pytest tests/
```
